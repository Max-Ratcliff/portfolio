Performing research under Dr. Marcella Gomez on machine learning for biological control and wound-healing systems. My earlier work engineered a fully automated Python and CellPose pipeline to segment bacterial spore microscopy images, extract morphology features, and support closed-loop population prediction with 0.3ms processing latency per image. More recently, I have been extending that lab work through HealNet, a PyTorch wound-healing model that uses ResNet image embeddings and multi-task heads to classify healing stage and forecast progression day, with the next phase focused on fusing image features with transcriptomic signatures.
